## 🚀 Featured Production Projects

### 🏥 [1. Healthcare Supply Chain Intelligence Platform (KEMSA Capstone)](https://github.com/Camilaaoko/Capstone_project)
* **Description:** End-to-end decision-support and inter-facility medicine redistribution platform spanning all **47 Kenyan counties and 235 health facilities**.
* **Tech Stack:** Python, Star-Schema ETL (Kimball), SQLite WAL, LightGBM, Plotly Dash, OpenStreetMap GIS.
* **Impact:** Slashed stockout duration by **68.3%**, cut expiry wastage by **42.1%**, and delivered **KES 39.08M in annual net savings** with a **2.6-month payback period**.

### ⚙️ [2. Industrial Predictive Maintenance & Telemetry Failure Classification](https://github.com/Sigei200/Week9_Operational-ML-Model-Explainability-Report)
* **Description:** Cost-sensitive machine learning failure detection pipeline on 10,000 industrial machine telemetry sensor streams with severe class imbalance (3.39% failure rate).
* **Tech Stack:** Python, Scikit-Learn, XGBoost, Random Forest, SHAP Explainable AI (XAI), Cost Matrix Optimization.
* **Impact:** Reduced unpredicted downtime by **70.2%**, saving **$124,000 in prevented equipment downtime costs**.

* **Description:** Interactive multi-scenario inventory simulation platform evaluating supplier lead-time shocks, vendor SLA scorecards, and dynamic safety stock optimization.
* **Tech Stack:** Python, Streamlit, Plotly, Pandas, Monte Carlo Simulation.
